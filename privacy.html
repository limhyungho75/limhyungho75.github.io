개인정보처리방침 (Privacy Policy)

최종 수정일: 2026년 10월 1일

1. 접근하는 Google 사용자 데이터

가족 캘린더는 사용자가 허용한 경우에 한해 Google Calendar API를 통해 사용자의 캘린더 목록과 일정 정보(제목, 날짜, 시간, 장소, 설명, 알림)에 접근합니다.

2. 데이터 사용 목적

접근한 데이터는 가족 구성원이 요청한 일정의 조회·등록·수정·삭제에만 사용합니다. 등록·수정·삭제는 사용자가 내용을 확인한 뒤에만 실행됩니다.

3. 데이터 저장

캘린더 데이터는 Google Calendar에 저장되며, 이 앱은 일정 데이터를 별도 서버에 복사해 보관하지 않습니다. 인증 토큰은 운영자 가정 내 서버에만 저장됩니다.

4. 데이터 공유

Google 사용자 데이터를 제3자에게 판매하거나 공유하지 않으며, 광고 목적으로 사용하지 않습니다.

5. 접근 권한 해제

사용자는 언제든지 Google 계정 권한 페이지에서 이 앱의 접근 권한을 해제할 수 있습니다.

6. Google API 서비스 사용자 데이터 정책 준수

이 앱의 Google API 정보 사용은 제한적 사용(Limited Use) 요구사항을 포함한 Google API Services User Data Policy를 준수합니다.
